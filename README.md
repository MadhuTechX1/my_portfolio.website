## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/MadhuTechX/MadhuTechX.github.io.git
   ```
2. Open the folder:
   ```bash
   cd MadhuTechX.github.io
   ```
3. Open `index.html` in any web browser.

No installation or build step is needed.

---

## Deploy on GitHub Pages

1. Create a public repository named `MadhuTechX.github.io`.
2. Upload `index.html` to the repository.
3. Go to **Settings, then Pages**.
4. Set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then save.
5. The site goes live at `https://madhutechx.github.io` after a minute or two.

---

## Editing the Content

All text content (skills, projects, experience, education and contact links) is stored in a single `DATA` object inside the `<script>` section of `index.html`. Edit the values there and commit the file to update the live site.
